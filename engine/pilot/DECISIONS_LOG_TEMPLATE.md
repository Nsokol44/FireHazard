county did." Keep it contemporaneous; a row written the same week is worth
ten reconstructed later.

## Pilot review checkpoints

- After the first 50 inspections: do the card "why" lines match what
  inspectors see on the ground? Note mismatches here.
- After the first mitigation recommendation: did the what-if ranking match
  the department's own cost sense? Note disagreements — they are config
  changes (weights/costs), not arguments.
- End of pilot: list every layer the county supplied as an override, and
  every place the national default was wrong locally. That list is the
  second county's head start.
