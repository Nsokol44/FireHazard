# FireScore

FireScore computes a five-component wildfire vulnerability score for every
structure in any US county, from free national data, with one command:

```bash
firescore run --county "Sevier, TN"
```

It is the operational form of the parcel-level vulnerability index in
Daniels & Sokol's "A Reusable, Open-Source Parcel-Level Wildfire
Vulnerability Index" — with the synthetic demonstration fixture replaced by
real data throughout. Start with the [Quickstart](quickstart.md), and read
[the offline workflow](offline.md) before taking it into the field.
